# FIELD 

**FIELD** — портативная утилита управления Windows 10 и Windows 11. В одном интерфейсе собраны сведения о компьютере, выборочная настройка системы, управление необязательными приложениями и автозагрузкой, монитор процессов и инспектор блокировок файлов.

## Запуск

Скачайте файл `FIELD.exe` из раздела **Releases** репозитория и запустите его двойным щелчком. **Установщик не требуется.** Для запуска готового EXE не нужны отдельно установленные Python, PySide6 или другие Python-зависимости.

> Готовый EXE следует собирать на Windows и проверить перед публикацией. Исходный репозиторий сам по себе не содержит готовый Windows EXE.

## Возможности

- **Сведения о системе:** Windows, редакция, версия, процессор, видеокарта и установленная оперативная память.
- **Твики:** отдельные настройки с просмотром и подтверждением изменений.
- **Приложения:** выборочное удаление необязательных встроенных Appx-приложений.
- **Автозагрузка:** просмотр и управление поддерживаемыми пользовательскими записями.
- **Процессы:** список процессов, поиск и ограниченные действия с подтверждением.
- **Lock Inspector:** определение программ, использующих выбранный файл, через Windows Restart Manager.
- **Профили и история:** сохранение наборов настроек и журнал выполненных действий.
- **Интерфейс:** тёмная/светлая тема, русский/английский язык, автоопределение языка Windows.

## Совместимость

Основные целевые версии — Windows 10 22H2 и Windows 11 24H2/25H2. Поддержка отдельных функций может зависеть от сборки Windows и прав доступа. Реальную совместимость необходимо проверить на конкретных компьютерах.

## Особенности портативной версии

- Не требует установщика и не устанавливает Python на компьютере пользователя.
- При запуске однофайловый EXE временно распаковывает служебные компоненты в системную временную папку. Это нормальная особенность PyInstaller.
- Настройки и журналы программы **могут сохраняться в AppData** — «один EXE» не означает отсутствие пользовательских данных на диске.
- Для системных операций могут потребоваться соответствующие разрешения; FIELD не должен обходить защиту Windows.
- EXE без цифровой подписи может вызвать предупреждение SmartScreen. Не отключайте защиту ради запуска неизвестных файлов.

## Для разработчиков

Для сборки одного `FIELD.exe` на **Windows** откройте исходники в VS Code и запустите `build_FIELD.bat`. Команда установит инструменты сборки **на компьютер разработчика**, затем создаст `dist\FIELD.exe`.

English documentation: [README_EN.md](README_EN.md).

## Безопасность и ограничения

FIELD не предназначен для отключения Defender, Windows Update или других важных механизмов безопасности. Удаление Appx не восстанавливается одной кнопкой; откат реализован только для поддерживаемых операций. Перед изменениями сохраняйте важные файлы.
