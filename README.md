# FIELD 1.2.1 — Winter Edition / Windows Control Center

Полный исходный проект FIELD, не патч. Python 3.11 + PySide6, Windows 10/11. Репозиторий: https://github.com/ewosony/FieldTweaker.


## Зимняя версия 1.2.1

- Праздничная палитра, светящиеся гирлянды и плавно падающий снег; все эффекты рисуются локально через Qt без доступа к интернету.
- Украшенная главная страница и бейдж **WINTER EDITION** на боковой панели.
- Кнопка **«❄ Зима: вкл/выкл»** в верхней панели: можно сразу вернуться к обычной теме FIELD.
- Работают обе светлые/тёмные темы, RU/EN и сохранение выбранного оформления в `%APPDATA%\FIELD\appearance.json`.
- При переключении оформления страницы не пересоздаются; это важно во время установки программ или очистки.
- Эффекты не взаимодействуют с мышью; снег автоматически останавливается, когда новогодняя тема выключена или окно скрыто.

## Возможности

- **Главная:** живые показатели CPU, памяти и свободного места; быстрый переход к настройкам.
- **Очистка системы:** просмотр объёма временных файлов, кэша миниатюр, дампов сбоев, старых отчётов и кэша браузеров; выбор категорий; подтверждение перед удалением. Файлы сканируются в пользовательских папках; свежие файлы пропускаются. Пароли, куки, история, документы и точки восстановления не очищаются.
- **Установка ПО:** 26 приложений, включая Steam, Firefox, Chrome, Discord, Telegram, OBS, Happ, Throne; поиск, фильтр категорий, базовый набор, проверка установленных через winget, обновление выбранных, прогресс очереди, журнал и остановка.
- **Электропитание:** выбор доступных схем Windows (баланс, экономия и производительность — только если они есть в системе), возврат к схеме, которая была активна перед первым изменением FIELD.
- **Расширенные настройки:** Windows Update с возможностью восстановления, политика обновления драйверов, фоновая запись игр, быстрый запуск и качество обоев.
- Также сохранены: классические твики, сведения о системе, системные приложения, автозагрузка, история, профили FIELD, монитор процессов и поиск блокирующих файлов.
- Русский и английский интерфейс, светлая и тёмная темы, встроенные страницы вместо дополнительных окон.

## Запуск

Распакуй архив в отдельную папку `FIELD_1.2.1`, открой там PowerShell:

```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 main.py
```

Можно использовать `run_FIELD.bat`. Не нужно скачивать старые исходники.

## Сборка EXE

```powershell
py -3.11 -m pip install --upgrade pyinstaller
.\build_exe.bat
```

Результат: `dist\FIELD 1.2.1.exe`. В BAT используются абсолютные пути к иконке и ресурсам, чтобы избежать ошибки PyInstaller с `--specpath`.

## Значки программ

В архиве **уже находятся 8 настоящих векторных брендовых значков в PNG** (Chrome, Firefox, Brave, Discord, Telegram, Steam, Git, Spotify). Остальные логотипы FIELD автоматически загружает через HTTPS при первом открытии «Установка ПО» и сохраняет в `%LOCALAPPDATA%\FIELD\brand_icons_v2`. Для ручного обновления есть кнопка **«Обновить иконки»** на странице.

Чтобы **включить загруженные логотипы в EXE** и сделать их доступными офлайн, перед сборкой запусти `python download_app_icons.py --bundle` (эта команда уже добавлена в `build_exe.bat`). Если загрузка какого-либо источника недоступна, используется резервный значок. Возможность загрузки не гарантирует, что каждый логотип появится при отсутствии сети.

Добавлены MSI Afterburner (`Guru3D.Afterburner`), HWiNFO, HWMonitor, Everything, ShareX, qBittorrent, Spotify, Audacity, Bitwarden, KeePassXC. MSI Afterburner устанавливается штатно через winget, FIELD не выполняет разгон видеокарты. Атрибуция и лицензии брендовых SVG: `assets/app_icons/ATTRIBUTION.md`. Использование логотипов не означает аффилиации с правообладателями.

## Безопасность

- Очистка выполняется только после сканирования и отдельного подтверждения. Удаление минует Корзину; сделай резервную копию, если файлы нужны для диагностики.
- Кэши браузеров доступны к очистке только при закрытых Chrome, Firefox и Brave. Утилита не удаляет историю браузера, данные профиля или авторизации.
- Windows Update может самостоятельно вернуть свои компоненты; полная блокировка не гарантируется. Без обновлений Windows остаётся уязвимой. Резервные настройки для восстановления хранятся в `%APPDATA%\FIELD`. Не удаляй их, пока нужен откат.
- Схемы питания не создаются и не модифицируются — FIELD лишь выбирает существующую. Для возврата используется сохранённый GUID.
- Перед релизом проверь функции на Windows 10 и 11, в том числе восстановление после твиков.

## Проверка исходников

```powershell
py -3.11 -m unittest discover -s tests -v
py -3.11 -m compileall -q personal_lite main.py
```

В среде сборки без Windows прошли офлайн-тесты; полноценный запуск GUI, winget, очистка и системные операции на Windows требуют проверки на реальном компьютере. Чек-лист в `MANUAL_TESTS.md`.
