# Анализ Optimization.rar для FIELD

Архив просмотрен **без запуска содержащихся в нём EXE, BAT, REG, VBS**. Структура: 196 записей, ~215 МБ распакованного содержимого. Изучены названия, перечень утилит и текстовые конфигурации/скрипты. Сторонние бинарные файлы не проверялись на безопасность и не распространяются в патче.

## Использовано как ориентир

| Материал внутри архива | Решение FIELD |
|---|---|
| `3) win updates/win update blocker.ini` | Идея переключателя «отключить / включить обратно»; **не использовать** сторонний блокировщик, перехват системных процессов, изменение защищённых служб и планировщика. Своя копия исходных настроек и откат. |
| `8) drivers/1) autoupdate/off.reg`, `backup/on.reg` | Исключение драйверов из Windows quality updates: обратимая опциональная настройка. |
| `6) tweaks/18) no gamebar.bat` | Только пользовательские настройки захвата Game DVR, без системной деактивации служб Game Bar. |
| `2) электропитание/3) отключить гибернацию.reg` | Только отключение Fast Startup; **не отключаем всю гибернацию**. |
| `6) tweaks/5) quality 100.reg` | Опциональное качество JPEG 100 (в архиве указано `dword:80`, то есть десятичное 128). |

## Не переносить

- `6) tweaks/13) turn off UAC.bat`: отключает UAC и SmartScreen.
- `6) tweaks/8) Spectre, Meltdown, TSX.reg`: изменяет параметры аппаратных защит.
- `6) tweaks/12) triggers off.bat`: массово отключает задания обслуживания Windows.
- `6) tweaks/21) mobsync.bat`: удаляет исполняемые файлы в системных папках.
- `7) hpet/1) turn off HPET.cmd`: меняет загрузочные таймеры без бенчмарка и проверки устройств.
- `8) drivers/3) network/1) bufferbloat fix.bat`: отключает TCP autotuning всем приложениям.
- `6) tweaks/4) desktop tweaks.reg`: уменьшает тайм-ауты закрытия приложений с риском потери несохранённых данных; MenuShowDelay уже есть в базовом FIELD.
- `1) win 10 activation/win 10 activation.bat`: сторонняя активация не относится к оптимизации.
- `9) optimization software/*`, `8) drivers/*/*.exe`, `3) win updates/win update blocker.exe`: сторонние двоичные инструменты; без проверки доверия и лицензий не включать в публичный продукт.
- `5) no ms edge/*`: принудительное удаление Edge может повредить связанные функции Windows.

## Итог

Наиболее полезное направление — **не набор агрессивных .reg/.bat**, а прозрачные обратимые переключатели, понятные объяснения и точное восстановление исходного состояния. Модули патча используют только стандартную библиотеку Python, WinAPI через системные утилиты и PySide6 FIELD.
