# FIELD 1.2.0 — обновлённая сборка исходников

- Убраны технические и привязанные к исходным скриптам подписи из GUI «Расширенные настройки».
- Добавлена полноценная главная страница: показатели CPU, RAM, диска и Windows, быстрые действия.
- Добавлен раздел «Очистка системы» с предварительным сканированием и выборочным удалением только старых файлов из разрешённых каталогов.
- Добавлены схемы электропитания через powercfg: список доступных и восстановление предыдущей активной.
- Установщик ПО: проверка установленных через winget, отдельное обновление выбранных, поиск, категории, базовый набор, счётчик и прогресс.
- Исправлена навигация с учётом жизненного цикла QProcess/QThread и прокрутка бокового меню.
- Дополнены русская и английская документация, тесты и сборочный BAT.

## Пожалуйста, протестируйте

Windows 10/11 GUI, winget, Windows Update, профили питания и очистка файлов не проверялись на настоящей Windows в этой среде. Используйте MANUAL_TESTS.md. Не публикуйте до локальной проверки.
