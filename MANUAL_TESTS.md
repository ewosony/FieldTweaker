# FIELD 1.2.1 — чек-лист тестирования на Windows

1. Запуск `py -3.11 main.py`; приложение должно открыть раздел **Главная**. Показатели CPU, RAM и диска отображаются без ошибок.
2. Навигация: Главная → Установка ПО → Очистка системы → Электропитание → Главная. Нет исключений `QProcess already deleted`.
3. Переключение RU/EN и светлой/тёмной темы во всех новых разделах. UI не открывает новые окна для разделов.
4. Установка ПО: поиск Firefox, фильтр «Браузеры», кнопка «Проверить установленные», выбор Firefox, установка через winget с явным подтверждением, вывод логов, проверка `winget list --id Mozilla.Firefox --exact`.
5. Установка ПО: выбери установленную программу → «Обновить выбранные». Если обновление не требуется, ошибка/ответ winget отображается в журнале. Во время работы нельзя покинуть раздел, не завершив операцию.
6. Очистка: открой страницу, проверь сканирование и категории; сначала не удаляй ничего. Закрой браузеры перед сканированием кэша. Проверь, что кнопка требует подтверждения и не затрагивает личные файлы.
7. Электропитание: проверь список доступных схем. Зафиксируй активную, переключи на другую, затем используй «Вернуть прежний режим». Сверь `powercfg /getactivescheme` до и после.
8. Расширенные настройки: сначала проверь чтение статусов. Изменение Windows Update тестируй только на тестовой системе/виртуальной машине и обязательно проверь восстановление.
9. История, профили, Appx, автозагрузка, сведения и монитор процессов должны открываться и работать как прежде.
10. Собери EXE через `build_exe.bat` и повтори пункты 1–4 на собранной версии. Не публикуй сборку с ошибками.

## Зимнее оформление 1.2.1

11. После первого запуска видны гирлянды вверху, мягкий снег, зимний бейдж и праздничная главная страница.
12. Кнопка «❄ Зима: вкл/выкл» выключает и снова включает украшения без перезапуска; в выключенном состоянии возвращается обычная палитра FIELD.
13. Проверь обе цветовые темы и переключение RU/EN; гирлянды и снег не должны перекрывать клики по меню.
14. Измени размер окна, открой другие разделы; украшения не должны обрезаться или зависать.
15. Запусти установку или сканирование и переключи зимнюю тему: работа не должна прерываться и не должно быть RuntimeError QProcess.
16. Закрой и открой FIELD: выбранное зимнее оформление должно сохраниться.
